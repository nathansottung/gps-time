# GPS Time v1.4.0-rc.11

**Date:** 2026-10-19 · **Type:** pre-release (release candidate) · **Previous:** [v1.4.0-rc.10](v1.4.0-rc.10.md)

Eleventh release candidate, and the bundle the deploy checklists target. It carries the fix for the last code release blocker, chrony history semantics (review GPS-003, GPS-007), and the port of the legacy pages' features into `/app/`. It replaces rc.10 as the candidate for the soak run: **v1.4.0 is to be tagged on this same commit after three clean days on the Pi.**

Source: `docs/provenance/change-log.md`, entries after v1.4.0-rc.10 (#81 to #95).

## Release blocker fixed

- **chrony history semantics** (#93; GPS-003, GPS-007):
  - `/api/history` reads chrony's tracking log by named column from the chrony 4.x layout, and skips (and counts) lines of any other shape instead of guessing. The old "error" field, which took whichever of three unrelated columns was non-negative, is gone.
  - `/api` adds `max_error_bound_s`: |System time| + root dispersion + ½ root delay, chronyc's bound, valid only if the reference is right.
  - Both UIs call chrony's System time the "remaining correction" (still being slewed out, not the error against UTC). They show the bound where they used to show "± root dispersion", and the light-distance figure uses the bound.
  - The legacy history chart's band is chrony's offset SD, never filled in.

## The legacy pages' features in `/app/`

All 21 parity items are now ported, decided or dropped (owner's decisions in `STATUS.md`). The legacy pages still work; switching `/` to `/app/` (removal step 7) is not in this release.

- **Administration** (#81, #82, #91): station actions with a confirmation step; position-survey reset with a typed confirmation; every throttle flag, now and since boot, with a warning on under-voltage.
- **Sun & Astronomy:**
  - Almanac (#87): date navigation, a 24 h twilight bar, a night bar with moon-up and moonless-darkness windows, and moon transit altitude and time up.
  - Sky & Objects (#88): the sky map and object lookup. The sky target is per request; the server-global target is removed (GPS-030).
- **GNSS & Site → Survey** (#89): convergence of the surveyed mean, this session's fixes, ingest counters.
- **Timing:**
  - chrony tracking detail (#89).
  - Offset history (#94): chrony's offset with ± its offset SD, ± its max-error bound, and a symmetric-log axis.
- **Configure** (#90): show or hide pages and Overview cards (per browser), and the red night theme.
- Legacy almanac sky map: E and W labels on the correct sides (#92).

## Dependencies

- TypeScript 7.0 for the web type check (#65; `baseUrl` dropped from `tsconfig.json`).
- Web minor and patch updates (#85).
- Dependabot no longer offers major `@types/node` updates; the types follow the toolchain's Node 22 (#83).

## What rc.10 showed in its first hours

Read-only check, 2026-10-19, after 2 h 17 min. Record: `development/raspberry-pi-deploy.md` → "First hours of v1.4.0-rc.10".

- **Outages:** three real losses of PPS (41 s, 231 s, 493 s), each starting with 0 satellites used and C/N₀ about 20–28 dB-Hz. There was also one expected event at the service start (the installer restarts chrony).
- **Missed pulses:** 812 missed (9.9 % of reads), 0 unread, no late reads. These are real absences, mostly within those outages, not a polling artifact.
- **Browser round trip:** 16 ms median.
