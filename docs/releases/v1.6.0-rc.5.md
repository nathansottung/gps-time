# GPS Time v1.6.0-rc.5

**Date:** 2026-11-04 · **Type:** pre-release (release candidate) · **Previous:** [v1.6.0-rc.4](v1.6.0-rc.4.md); last stable [v1.4.0](v1.4.0.md)

rc.4 with the owner's rc.5 list (2026-11-04), in one PR (#171): the web SDR's login made optional, its decoders and band bookmarks, and its HF limits. Everything in rc.1 to rc.4 is still here. v1.5.0 stays skipped. **The formal soak waits for the antenna move.**

None of these changes chrony, gpsd or the PPS setup. All of it is inside the optional web SDR (`GTP_WEBSDR=1`).

## What's new

| What | Guide |
|---|---|
| **The web SDR's login is optional, off by default.** `GTP_WEBSDR_AUTH=1` turns it on: a sign-in page with **Remember this browser**, a signed cookie (`HttpOnly`, `SameSite=Strict`) for `GTP_WEBSDR_REMEMBER_DAYS` (default 30). A new password or **Sign out all browsers** (Web SDR card, admin token; or `websdr_gate signout-all`) revokes every cookie at once. Start and Stop always need the admin token. | `deploy/websdr.md` → "Login (optional)"; ADR-0009 amended |
| **Decoders:** SSTV, FT8, FT4, WSPR, APRS, packet, CW, RTTY and fax. The installer adds `direwolf`, `wsjtx`, `aprs-symbols` and `csdr-skimmer`; SSTV, fax, CW and RTTY are built into OpenWebRX+. **Band profiles** for 10 m, 6 m and 2 m digital, and **68 bookmarks** that select their decoder. | `deploy/websdr.md` → "Decoders and band bookmarks" |
| **HF:** the NESDR SMArt v5 can receive below about 25 MHz by Q-branch direct sampling. `GTP_WEBSDR_HF=direct` adds HF profiles for it (`native` for a dongle with its own HF path, such as the RTL-SDR Blog V4). The limits are written down: no LNA or filter, aliasing, an HF antenna, lightning. | `deploy/websdr.md` → "HF (below 24 MHz)" |

API additions: `/api/websdr` → `auth` (`enabled`, `remember_days`) and `hf`; `POST /api/admin` → `websdr_signout_all`. The reference is `api/endpoints.md`.

## What the upgrade changes on the station

Only with the web SDR installed (`GTP_WEBSDR=1` now or before):
- **The login is off after the upgrade.** An install from before rc.5 has no `GTP_WEBSDR_AUTH` line, so anyone on the LAN can listen while the web SDR runs. The password file is kept. To keep a login, deploy with `GTP_WEBSDR_AUTH=1`. The installer prints which it is.
- **New files:** `/etc/gps-time-websdr/cookie-key` (0600), `gps-time-websdr-signout.service`, and `/etc/openwebrx/bookmarks.d/gps-time-decoders.json`.
- **`/var/lib/openwebrx/settings.json`** gains the station's profiles (keys `gtp-*`) on each RTL-SDR. A copy of the old file is left beside it as `settings.json.gps-time-prev`, and the owner's own profiles are kept.
- **Packages:** `direwolf`, `wsjtx`, `aprs-symbols`, `csdr-skimmer` (if not already pulled in as Recommends).
- **The polkit rule** allows the web service to start `gps-time-websdr-signout.service`.

Without the web SDR, nothing changes but the polkit rule's one line.

## Deploy

From a clean working tree on Windows, in a normal PowerShell window:

```powershell
git fetch --tags
git checkout v1.6.0-rc.5
git describe --tags --dirty          # must print exactly v1.6.0-rc.5
powershell -ExecutionPolicy Bypass -File .\scripts\deploy-to-pi.ps1 -PiHost $PiHost -PiUser $PiUser
git checkout main
```

**With the web SDR**, set its flags in the same window before the deploy command:

```powershell
$env:GTP_WEBSDR = '1'                   # install or update the web SDR
$env:GTP_WEBSDR_AUTH = '1'              # optional: the login on (default off: anyone on the LAN can listen)
$env:GTP_WEBSDR_REMEMBER_DAYS = '30'    # optional: "Remember this browser" lasts this many days (1–365)
$env:GTP_WEBSDR_HF = 'off'              # optional: 'direct' for HF by direct sampling (NESDR SMArt v5), 'native' for a V4
$env:GTP_WEBSDR_SERIAL = '00001090'     # only if the SDR stack has no 1090 MHz serial set
```

With the login on and no password yet, set one on the Pi (`deploy/websdr.md`). Remove the flags after the deploy (`Remove-Item env:GTP_WEBSDR*`) so a later deploy doesn't pass them again; the settings are kept on the Pi in `/etc/default/gps-time-websdr`.

## Rollback

Check out `v1.6.0-rc.4` and run the same deploy command. rc.4's gate asks for the password again (Basic), and it ignores the cookie key, the new settings lines and the bookmarks file. The `gtp-*` profiles stay in `settings.json` until removed on OpenWebRX+'s settings page, or `settings.json.gps-time-prev` is copied back. `GTP_WEBSDR=0` removes the units and the bookmarks file.
