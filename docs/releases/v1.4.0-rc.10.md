# GPS Time v1.4.0-rc.10

**Date:** 2026-10-19 · **Type:** pre-release (release candidate) · **Previous:** [v1.4.0-rc.9](v1.4.0-rc.9.md)

Tenth release candidate, and the bundle the deploy checklists target. It adds the last two queued UI fixes from the owner's list and the documents for outside readers. Over rc.9 only the web UI changed: the station's timing, services, files and API are as in rc.9. It is the candidate for the soak run before v1.4.0.

Source: `docs/provenance/change-log.md`, entries after v1.4.0-rc.9 (#77 to #80).

## New

- **Sunset as prominent as sunrise** (#78): in the legacy dashboard's Sun & daylight widget, sunset was the small grey line under the sunrise figure. Each day now has two figures of the same size, each labeled. The `/app/` Overview already showed both at one size.
- **Screenshot mode** (#79), in `/app/`: a header toggle labeled "display only", shortcut Alt+Shift+S, remembered per browser. It hides latitude and longitude, heights (h, H and N), NTP client addresses, the hostname and the station's own address when chrony polls it. Each value is drawn as a blurred mask of the same shape (`38.9217°` → `00.0000°`); the real value is not drawn. Nothing changes on the station, in the API, in exports or in the location privacy mode. Sun and moon times, sidereal time and the zone stay visible; they narrow the position only coarsely (use the station's rounded or hidden mode for those). Not in the legacy pages.
- **Docs** (#77): `docs/ROADMAP.md`, one page for outside readers with every spec and roadmap by phase and status; a three-line vision in the README; the geophysics and distributed-science roadmap (FUTURE, research); a draft public release checklist (the repository stays private).
