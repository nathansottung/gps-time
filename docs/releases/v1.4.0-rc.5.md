# GPS Time v1.4.0-rc.5

**Date:** 2026-10-04 · **Type:** pre-release (release candidate) · **Previous:** [v1.4.0-rc.4](v1.4.0-rc.4.md)

Fifth release candidate, and the bundle the two deploy checklists target. It adds Debian 13 (Trixie) and Python 3.13 as a tested combination. **Nothing in the 1.4 line has run on a Pi yet.**

Source: `docs/provenance/change-log.md`, entries after v1.4.0-rc.4 (#38, #39).

## Debian 13 and Python 3.13 (#38)

- CI runs the tests on Python 3.11 (Debian 12) and 3.13 (Debian 13). All 187 pass on both.
- CI installs the runtime dependencies in a venv on each version, and checks that each has an aarch64 wheel, so the station never needs a compiler.
  - On 3.13, `skyfield==1.55` resolves to numpy 2.5.3, sgp4 2.27 and jplephem 2.24.
  - On 3.11 it resolves to numpy 2.4.6.
  - Only skyfield is pinned; the others float.
- `install.sh`:
  - no longer changes the mode of an existing `/etc/polkit-1/rules.d`, which Debian's polkitd package owns;
  - warns in its preflight if polkit isn't installed.
- The fresh-install checklist names both releases, installs `polkitd` and `python3-venv` explicitly, verifies the serial console is off, and checks chrony's RAM tracking log.

No change to chrony, gpsd or PPS configuration. No change to the application code.

## What `install.sh` does to timing on every run

Unchanged since v1.3: it makes sure `chrony.conf` has `log tracking` and `logdir /run/chrony-log`, and it **restarts chrony**.

## Known open issues

- Not verified on a Pi: systemd hardening, the polkit rule, `_chrony` socket access, `vcgencmd` under `video`, the venv install, the deploy scripts, the web UI install.
- The almanac with the real JPL ephemeris hasn't been run on Python 3.13 with numpy 2.5; the tests stub the astronomy layer. Check the Sun and Almanac pages after the deploy.
- A 32-bit Raspberry Pi OS (`armv7l`) isn't covered by the wheel check.
- chrony history semantics (GPS-003, GPS-007); unbounded RAM tracking log (GPS-011, GPS-012).
- GPS-020 remainder: hash-pinned requirements, ephemeris trust-on-first-use, staged install.
- Full list: `docs/STATUS.md`.
